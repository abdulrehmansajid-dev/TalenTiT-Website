# COO Organizations Section Design

**Date:** 2026-10-15  
**Status:** Approved (Approach A)

## Goal
Add a compact “Reputed Organizations Zeeshan Has Worked With” logo grid to the COO profile on About, after High Power Leadership.

## Placement
Inside the COO profile container, immediately after the High Power Leadership card.

- Eyebrow: Career Affiliations
- Title: Reputed Organizations Zeeshan Has Worked With
- Short supporting line + orange accent bar
- Responsive grid: 3 / 4 / 6 / 7 columns
- Each cell: light tile, logo (~56–72px visual), org name below
- Subtle hover (lift + orange border tint)
- Match existing COO slate/white/orange language

## Assets

- Lazy-loaded images

## Out of scope
